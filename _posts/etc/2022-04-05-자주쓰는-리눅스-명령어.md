## 1. 서버로그 확인 시 유용한 명령어

- `$ tail -f 파일명.log`
    - 실시간으로 올라오는 로그 확인 시 주로 사용

- `$ tail -f 파일명.log | perl -pe 's/키워드/\e[31m$&\e[0m/'`
    - 실시간으로 올라오는 로그 중 특정 키워드를 강조하여 확인 시 사용
    - s/매칭할정규식/교체할문자열/
    - \e : 회피문자(escape character)
    - [31m : 빨간색으로 변환
    - [0m : 원상태로 변환

- `$ tail -f 파일명.log | grep '키워드'`
    - 특정 키워드가 포함된 실시간 로그만 확인하고 싶을 때 사용

- `$ cat -n 파일명(or 패턴사용가능 ex.파일*) | grep '키워드'`
    - 특정 키워드로 로그 찾을 때 사용

- `$ find . -name '*.log' | xargs grep -r --color=auto -n '키워드'`
    - 현재 폴더 안의 log 형식의 파일중 키워드가 포함된 내용 출력 및 키워드 강조
    - 파일명, 라인넘버까지 확인 가능

## 2. 방화벽 정책 확인 시 유용한 명령어

- `$ telnet naver.com 80`
    - 특정 호스트의 포트가 열려있는지 확인할 때 사용
    - 연결 성공 시 `Connected to naver.com.` 메시지 출력
    - 연결 실패 시 `Connection refused` 또는 타임아웃 발생

- `$ telnet naver.com 443`
    - HTTPS 포트(443) 방화벽 오픈 여부 확인

- `$ curl -v telnet://naver.com:80`
    - telnet이 설치되어 있지 않은 환경에서 curl로 대체하여 포트 확인 가능
    - 연결 성공 시 `Connected to naver.com` 메시지 출력

- `$ curl -I https://naver.com`
    - HTTP 응답 헤더만 확인하여 서버 연결 상태를 빠르게 점검할 때 사용
    - 정상 시 `HTTP/2 200` 등의 상태코드 반환

- `$ curl -o /dev/null -s -w "%{http_code}" https://naver.com`
    - HTTP 상태코드만 간단하게 확인할 때 사용
    - 정상 연결 시 `200` 출력

## 3. 디스크 용량 확인 명령어

### 전체 디스크 용량 확인 (df)

- `$ df -h`
    - 파일시스템별 전체/사용중/남은 용량을 사람이 읽기 쉬운 단위(G, M)로 출력

- `$ df -h /home`
    - 특정 경로가 속한 파일시스템의 용량만 확인

- `$ df -hT`
    - 파일시스템 타입(ext4, xfs 등)까지 함께 출력

### 디렉토리별 사용 용량 확인 (du)

- `$ du -sh *`
    - 현재 디렉토리 하위의 디렉토리/파일별 용량을 요약하여 출력

- `$ du -sh /var/log`
    - 특정 디렉토리의 전체 사용 용량 확인

- `$ du -h --max-depth=1 /home`
    - 지정 경로의 1단계 하위 디렉토리별 용량 확인

- `$ du -sh /var/log/* | sort -rh | head -10`
    - 용량이 큰 순서대로 상위 10개 항목 확인
    - 디스크 정리가 필요할 때 유용
